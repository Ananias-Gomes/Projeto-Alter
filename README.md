Alter. 🎯
"A estética da função aplicada à disciplina diária."

O Alter é uma aplicação minimalista de produtividade e rastreio de hábitos, focada em ajudar o utilizador a manter o foco no seu Ikigai e nos seus objectivos diários. O design foi inspirado na estética "clean" do Notion e na metodologia de 66 dias do Life Reset.

🚀 Funcionalidades (MVP)
 Autenticação: Sistema de login com validação no backend.
 Check-in Diário: Registo de progresso em texto.
 Design Minimalista: Interface sublime focada na ausência de distrações.
 Dashboard de Evolução: (Em desenvolvimento) Visualização de streaks e progresso.
🛠️ Tecnologias Utilizadas
Frontend
HTML5 & CSS3: Estrutura e estilização com foco em tipografia (Inter) e espaçamento.
JavaScript (Vanilla): Lógica de manipulação do DOM e consumo de API via fetch.
Backend
Node.js: Ambiente de execução para o servidor.
Express: Framework para gestão de rotas e pedidos HTTP.
CORS: Segurança e permissão de comunicação entre domínios.
